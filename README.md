✨ Key Architectural Features
1. 🖥️ Bespoke Developer Hero Section
Dual-Column Grid: Modeled after modern high-end developer portfolios with personal brand storytelling on the left and a live macOS/cyber terminal card on the right.
Dynamic Typewriter Engine: Character-by-character typing loop cycling across roles:
`Aspiring AI & ML Engineer`
`B.Tech Scholar @ JECRC`
`Creative Web Architect`
`Algorithmic Problem Solver`
`IBM Watsonx Certified`
One-Click Clipboard Email: Interactive `Copy Email` button with acoustic feedback and floating `"COPIED! ✓"` tooltip toast.
Interactive Terminal Profile Node:
Rotating animated neon gradient aura (`animate-spin-slow`) surrounding the avatar.
Active status online indicator (`● ACTIVE`).
Syntax-highlighted C code snippet (`#include <stdio.h> ... printf("Building with AI & C\n")`).
Real-time rotatable 3D wireframe polytope core (`#hero-3d-canvas`) embedded directly inside the terminal.
---
2. 🌌 Lively Cosmic Synaptic Background Canvas
130+ Celestial Particles: Multi-depth background stars with soft sinusoidal twinkling and physical drift.
Direct Mouse Constellation Web: Moving the cursor over the screen causes nearest stars within 180px to cast bright glowing synaptic filaments directly to the mouse cursor, transforming the pointer into an active cosmic gravity nexus.
Stardust Particle Trail: Cursor movements leave behind a luminous stardust wake of micro-sparks that gently float with momentum and dissolve.
Gravitational Impulse Waves: Clicking anywhere on the canvas emits expanding concentric shockwave rings that physically displace particles with spring recovery.
Breathing Ambient Nebulae: Layered background CSS meshes with organic keyframe breathing in electric cyan, deep purple, and royal blue.
---
3. 🪟 Windows Fluent Glowing Hover Effect (Strictly for Cards)
Local Cursor Coordinate Tracking: Dynamically updates CSS custom properties `--mouse-x` and `--mouse-y` for every card on hover.
Radial Border Spotlight: Uses CSS `mask-composite: exclude` / `-webkit-mask-composite: xor` to cast a sharp, silky cyan-to-purple beam along the card's border directly under the cursor.
Ambient Glass Illumination: Soft radial ambient light shines through the frosted glass surface under the pointer.
Scoped Exclusively to Cards: Applied only to `.tilt-card` and `.fluent-card` containers without leaking onto text or navigation.
---
4. 🧊 3D Perspective Tilt & Optical Parallax
Physical Z-Space Stacking: Configured with `preserve-3d` and `perspective: 1200px`.
Multi-Layer Parallax: Child badges, icons, headings, and code snippets use `.z-layer-10` through `.z-layer-50` (`translateZ(10px)` to `translateZ(60px)`), producing genuine optical parallax depth as cards tilt.
Ray-Traced Specular Sheen: Calculates mouse angle relative to card bounds, casting dynamic specular gloss reflections across card borders.

⚡ Quick Start & Local Preview
No heavy `npm install` or node build steps required. The portfolio is 100% self-contained and runs immediately in any modern browser.
Option 1: Direct File Open
Double-click `code.html` or open it directly in Chrome, Edge, Brave, or Firefox.
Option 2: Local HTTP Server (Recommended)
Using Python:
```bash
python -m http.server 8000
```
Then navigate to `http://localhost:8000/code.html` in your browser.
Using Node.js:
```bash
npx serve .
```
